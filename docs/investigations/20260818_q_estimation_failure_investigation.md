## 1. Executive Summary

The library's Q estimators are not failing because the data are noisy. They are failing
because the **signal model is wrong for this resonator**, in three specific, measured ways:

1. **The resonance frequency is not constant during the decay.** It shifts by
   0.3–1.1 mHz as the amplitude decays (an amplitude-dependent anharmonic pull). Every
   phase-coherent estimator in the library (`Q_nls`, `Q_dft`, `Q_profile`) assumes a
   single constant frequency and phase over a multi-hour window; the measured drift
   exceeds the coherence tolerance ($\delta\!f\cdot\tau \lesssim 0.01$, i.e. ≈ 3 µHz for
   $\tau \approx 3700$ s) by **two to three orders of magnitude**. Under this violation
   the least-squares landscape has many near-degenerate minima, and the coherent Q
   becomes a lottery over noise realization and initialization — measured span ≈ 0.5×
   to 3.8× of truth on drift-injected synthetics — while continuing to report
   `status="valid"` with confidence intervals of relative width $10^{-4}$.
2. **The decay is not a single exponential.** The local decay time grows ≈ 2–3× from the
   highest to the lowest observable amplitude band (amplitude-dependent damping, local
   Q ≈ 6.5×10⁴ → 1.8×10⁵). A
   single-$\tau$ fit therefore returns a *window-dependent average* — which is why manual
   `tau_init`/duration tuning appears to "change Q": different windows genuinely have
   different mean decay rates.
3. **The oscillation never decays to zero.** Both records settle at an ambient-driven
   equilibrium amplitude of ≈ 17 cycles (with wandering, deep nulls, and re-excitation
   revivals). This is coherent *signal* at the analysis frequency, not measurement noise
   (broadband noise is only ≈ 1.5 cycles RMS). It biases envelope-slope estimators high
   once the analysis window extends past the point where the decay meets ≈ 3× the plateau.

Each mechanism was demonstrated by controlled experiments: starting from a synthetic
record that all estimators handle exactly, injecting **only the measured Pre-Vibe
frequency trajectory** reproduces the real `Q_profile` failure class — arbitrary
valid-but-wrong values at 0.51×, 1.77×, and 3.80× of truth depending on seed and
initialization, matching the real canonical windows (0.65× Pre, 0.25× Post, with the
same Pre window returning 0.45× in a session differing only at round-off level) — and
injecting only the driven plateau reproduces the envelope bias. Broadband noise at the
measured level produces no failure.

The practical consequences and the fix are summarized in §18–§21: the default Q path for
real data should be an **incoherent, segment-demodulated envelope estimator with an
explicit plateau model and amplitude-resolved output**, with the coherent estimators
retained for short/coherent records and *gated by a drift diagnostic and a
coherent-vs-incoherent consistency check* that the library already half-possesses
(`q_envelope_diagnostic` candidate agreement) but does not use for validity.

As a by-product, the Pre-Vibe/Post-Vibe physics question is answered defensibly
(notebook §4): at matched amplitude the Post-Vibe Q is equal or *higher* than Pre-Vibe
(whole-decay average +13 %; band-resolved +4 % to +51 % — no damage signature); the
resonance frequency dropped by ≈ 66 ppm (high amplitude) to ≈ 157 ppm (low amplitude);
and the frequency–amplitude pull coefficient weakened from ≈ −0.42 to ≈ −0.09 mHz per
amplitude e-fold (≈ 5×). Earlier single-number claims (−30 % Q from `Q_profile`, +27 %
from `Q_nls_raw`) were estimator artifacts.

## 2. Problem Statement

The library's estimators perform excellently on the synthetic records used in tests and
Monte-Carlo studies but frequently produce Q values on real EDU/ODIN phasemeter data that
visibly contradict the measured decay envelope — most obviously in
`plot_q_envelope_overlay`, where the envelope implied by the estimated Q decays much
faster or slower than the data. Prior handoffs
(`docs/handoffs/20260513_q-estimation-reliability-implementation.md`,
`…_q-profile-estimator-implementation.md`, `…_q-overlay-real-data-followup.md`)
progressively hardened validity gating and added the profile-likelihood estimator, yet the
overlay still exposes wrong-but-"valid" Q values, and results remain fragile under
`tau_init`, start time, and duration changes. The task: find the actual cause(s), with
evidence, and define the path to a reliable Q system.

## 3. Current Q-Estimation Architecture

Pipeline (`RingDownAnalyzer._run_analysis_pipeline`, `ringdownanalysis/analyzer.py:644`):

1. **Ingestion** — `analyze_file` loads CSV/MAT (time col 0, phase col 3), constant
   detrend, $f_s = 1/\mathrm{median}(\Delta t)$ with uniformity check
   (`analyzer.py:244–282`). `analyze_array` takes arrays; `detrend="constant"` optional.
   ODIN `.csv.zip` files are loaded outside the library by `mokutools`.
2. **$\tau$ seed** — RMS-window 1/e crossing or user `tau_init`
   (`estimators.py:342–385`).
3. **Full-record NLS `tau_est`** — 5-parameter bounded fit of
   $A_0 e^{-t/\tau}\cos(2\pi f t + \phi) + c$ (`analyzer.py:322–454`).
4. **Crop** to `max_tau_multiplier × tau_est` (default 3.0), min 1000 samples
   (`analyzer.py:456–520, 688–695`).
5. **Cropped NLS and DFT+fixed-f NLS** → `Q_nls_raw`, `Q_dft_raw` = $\pi f \tau$,
   assessed by `_assess_q_estimate` (`analyzer.py:159–241`) into
   `Q_nls`/`Q_dft` + status/reasons.
6. **Profile-likelihood Q** (`q_profile.py`) — the *recommended* estimator: frequency
   **fixed** at `f_nls` (or `f_dft`), variable projection of
   $a\,e^{-t/\tau}\cos\omega t + b\,e^{-t/\tau}\sin\omega t + c$ over a $\log\tau$ grid on
   the **full** selected window, 95 % interval from
   $\Delta = \nu\,\log(\mathrm{RSS}/\mathrm{RSS}_{\min}) \le \chi^2_{0.95,1}$
   (`q_profile.py:317–318`). Finite `Q_profile` only if the interval closes both sides.
7. **Envelope diagnostic** (`q_envelope.py`) — sliding 3-cycle windows, robust
   peak-to-peak amplitude $\tfrac12(P_{95}-P_{5})$, log-linear fit over windows with
   $A \ge 5\%\,A_{\max}$ with MAD outlier rejection → `Q_envelope`; also compares a
   candidate Q against the measured envelope (`candidate_agrees`).
8. **Overlay** (`plots.py:151–251`) — recomputes the diagnostic and draws the candidate
   envelope $\exp[\log A_{\mathrm{used},0} - (t - t_{\mathrm{first\,used}})/\tau_c]$,
   $\tau_c = Q/(\pi f)$, anchored at the *first used window's measured amplitude*, around
   `median(data)`. `q_source="best"` prefers `Q_profile` → `Q_nls` → `Q_dft` →
   `Q_envelope` → `Q_nls_raw` (`plots.py:105–148`).
9. **Batch** (`batch_analyzer.py`) prefers valid `Q_profile`.

Every estimator in steps 3–6 is **phase-coherent**: it assumes one constant $f$ and $\phi$
across the whole fit interval. Step 7 is incoherent (window peak-to-peak) but has **no
noise/plateau model**. This split is the crux of the failure analysis.

| `tau_est` | 17 692 s (4.6× envelope τ) | 1475 s (0.33× envelope τ) |
| `Q_profile` | **58 141, `valid`, CI (58 103, 58 245)** | **25 078, `valid`, CI (25 071, 25 084)** |

- The *recommended, "validated"* `Q_profile` is **1.5× low (Pre)** and **4.0× low (Post)**,
  with confidence intervals of relative width ≈ 10⁻⁴ that are statistically meaningless.
- The result is **not even reproducible**: an earlier session running the *same* Pre-Vibe
  window (inputs differing only at numerical round-off level) returned
  `Q_profile` = 40 035 (`valid`, 2.2× low) with `tau_est` = 1736 s instead of 17 692 s.
  Round-off-level input changes select different local minima of the decoherent
  objective — the ill-conditioning demonstrated directly on the §5.1 specimen below.
- The overlay shows exactly this: the red profile-Q envelope decays visibly faster than
  the data; only the envelope diagnostic (green) tracks the data, and only it warns.
- Window sensitivity (notebook §5.4, `fig10_window_sensitivity.png`): across ordinary
  window choices (start 0/1800 s × duration 1–6 h), Pre-Vibe `Q_profile` scatters
  **6.5×10³ … 7.5×10⁴ (12×)**, `Q_nls_raw` ≈ 4×, `Q_envelope` drifts up
  7.3×10⁴ → 1.4×10⁵ with duration. Post-Vibe `Q_profile` is *stably wrong* (≈ 2.7×10⁴
  everywhere — smoother drift trajectory, same bias).
- A window offset deep into the record (Post-Vibe +9000 s; notebook §5.1) triggers a
  **catastrophic cascade**, and exposes extreme ill-conditioning: two selections of the
  *same* window that differ only by float round-off in the time array (same $N$, same
  span) give `tau_est` = **35.6 s** (crop = 107 s = 0.8 % of the data, `Q_profile` →
  `upper_limit`) in one variant and `tau_est` = **1051 s** (crop = 3154 s, `Q_profile` =
  2.79×10⁴ reported **`valid`**, vs envelope ≈ 1.3×10⁵) in the other. Both collapse far
  below the 5698 s envelope seed; ULP-level input differences select different local
  minima because the decoherent objective has no meaningful optimum.

## 5. Evidence From Experimental EDU Data

Measured signal properties (notebook §1–3, `fig03`–`fig05`):

- **Single mode.** High-resolution spectra of early (decay) and late (plateau) segments
  show one dominant peak at ≈ 7.669–7.672 Hz; nearest secondary features are ~10⁵× weaker
  and consistent with leakage sidebands of the drifting tone. Beating/multi-mode is ruled
  out (`fig04_spectra.png`).
- **Frequency drift.** Segmented demodulation (120 s segments) shows $f$ rising smoothly
  by **+1.09 mHz** (Pre) / **+0.29 mHz** (Post) during the decay, monotonically with
  *decreasing amplitude* — an anharmonic pull, ≈ linear in $\log A$
  (`fig05`, right panel). A 1 mHz error against a fixed-frequency model accumulates a
  full cycle of phase slip in ≈ 1000 s.
- **Non-exponential decay.** Floor-corrected log-envelope residuals show smooth curvature
  far above segment scatter. Local Q per amplitude band rises from 6.5×10⁴/8.3×10⁴
  (Pre/Post, 400–700 cycles) through 8.3×10⁴/1.24×10⁵ (100–200 cycles) to ≈ 1.8×10⁵
  (both, 60–100 cycles; this lowest band carries the largest floor-correction
  uncertainty) — local $\tau$ 2696 → 7325 s (Pre), 3439 → 7628 s (Post)
  (`fig05`, left/middle panels; band table in notebook §3.2).
- **Driven plateau.** Both records settle at ≈ 16.5–17.6 cycles with amplitude wandering,
  deep nulls, and revivals (Post-Vibe up to ≈ 50 cycles near +48 000 s). The tone is still
  present at high power in the plateau spectra: the resonator is continuously re-excited
  by ambient drive. This is signal, not noise.
- **Noise levels.** Per-segment broadband residual ≈ 1.3–1.9 cycles RMS
  (SNR ≈ 400 at release); baseline wander ≈ 10–25 cycles over hours.
- **Uniform sampling** to ≈ 1.5×10⁻⁴ relative; `fs` assumptions are correct.

## 6. Synthetic vs Experimental Signal Comparison

The library's synthetic generator (`signal.py`: $A_0 e^{-t/\tau}\cos(2\pi f_0 t+\phi)$ +
white Gaussian noise) matches the estimators' model *exactly* — constant $f$, constant
$\tau$, decay to zero, white noise. The experimental signal violates constant $f$,
constant $\tau$, and decay-to-zero, and its dominant "residual" (the plateau) is
narrowband and centered exactly on the analysis frequency. **The synthetic/real
performance gap is fully explained by these three violations** (§9): estimators are exact
on the matched-SNR ideal record (E1) and reproduce the real failures when the measured
pathologies are injected one at a time (E2c, E3).

The drift-immune reference used throughout ("segmented demodulation") splits the record
into 120 s segments, fits $a\cos + b\sin + c$ per segment with a two-stage frequency scan,
and fits $\log\sqrt{A^2 - A_{\rm floor}^2}$ vs $t$ over the contiguous region with
$A > 3A_{\rm floor}$. On synthetic records with known Q it is accurate to < 0.5 % in all
tested conditions, including under measured drift (E2c: −0.01 %) and plateau
(E3: −1.7 %).

## 7. Investigation Methodology

1. Read the complete estimation pipeline at source level (§3).
2. Reproduce the failure on the canonical EDU windows and on window sweeps (§4).
3. Characterize the real signal with estimator-independent diagnostics: segmented
   demodulation, high-resolution spectra, envelope statistics (§5).
4. Check every model assumption explicitly against measurement (§8, table in notebook §5).
5. Controlled experiments: begin from a synthetic record the estimators handle exactly;
   inject the *measured* pathologies one at a time; run the full analyzer and the
   reference estimator on each (§9).
6. Sensitivity scans to derive quantitative thresholds (§9, §11).
7. Cross-check alternative estimation approaches (§14).

All experiments are reproducible in the companion notebook with fixed seeds.

## 8. Root-Cause Analysis

**Mechanism A — decoherence of phase-coherent fits (primary).**
All of `estimate_tau`, `NLSFrequencyEstimator.estimate_full`, DFT+fixed-$f$ NLS, and
`ProfileQEstimator` fit a model that is phase-locked to a constant frequency for the whole
window. With measured drift, the model inevitably runs anti-phase after the coherence
time; beyond that point a *large-amplitude* model **increases** the residual relative to
fitting nothing. Least squares therefore trades away the incoherent late portion, moving
$\hat\tau$ (and $A_0$) to whatever compromise maximizes coherent overlap. Consequences:

- Bias of ≈ 0.5–3.8× in $\hat\tau$ depending on the drift trajectory's shape *and* on
  nominally irrelevant inputs (noise seed, `tau_init`): under decoherence the objective
  has many near-degenerate minima and the fit converges to an arbitrary one —
  E2/E2b/E2c, §9.
- Occasional total collapse of `tau_est` (τ → tens of seconds) when the window is
  plateau-dominated, which then **poisons the crop** (Mechanism D).
- The profile CI is computed from RSS curvature under a white-noise assumption with
  $N \sim 10^6$; under misspecification it shrinks to nothing while the estimate is far
  from truth. **The `valid` status tests interval closure, not model adequacy** — it is
  structurally unable to catch this failure.

**Mechanism B — window-dependent "Q" from amplitude-dependent damping (physical).**
Local $\tau$ varies ≈ 2–3× across the observable amplitude range in both records. Any
single-$\tau$ estimator returns an average weighted by its window and its (implicit)
amplitude weighting — NLS weights early high-amplitude data, the log-envelope fit weights
all used windows equally. Estimates legitimately differ across windows and estimators
even when nothing is "broken". No single number is the answer; Q must be reported vs
amplitude (or via a nonlinear-damping model).

**Mechanism C — driven plateau biases envelope estimators (secondary).**
`q_envelope_diagnostic` fits all windows with $A \ge 5\%\,A_{\max}$; the plateau
(≈ 17/600 ≈ 2.8 % of $A_{\max}$, but up to 8 % during revivals and for shorter windows'
smaller $A_{\max}$) enters the fit for long windows and flattens the slope. Measured
bias: ≈ 0 (1–2 h) → +7 % (6 h) on synthetic; larger on real data where it compounds
with Mechanism B.

**Mechanism D — crop cascade (design flaw).**
`crop_data_to_tau` trusts `tau_est` unconditionally (subject only to `min_samples=1000` —
which a 107 s crop at 149 Hz passes easily). A decoherence-collapsed `tau_est` silently
reduces the analysis to a sliver of data (§4, specimen). The envelope-based seed that the
pipeline *already computes* (5698 s in the specimen) is discarded in favor of the
collapsed NLS value. The specimen's two round-off-level variants (35.6 s vs 1051 s)
show that on decoherent data the collapse magnitude is essentially arbitrary — and that
one arbitrary outcome can carry `status="valid"`.

## 10. Envelope-Estimation Analysis

Representations in play: the library uses **windowed robust peak-to-peak percentile
amplitude** ($\tfrac12(P_{95}-P_{5})$ over 3-cycle windows) — a good choice for these data
(insensitive to phase, robust to spikes; for a pure sinusoid it reads 0.987 A). Hilbert
envelopes were not needed: at 19 samples/cycle and SNR 400, windowed P2P and segment
demodulation agree; segment demodulation additionally yields per-segment frequency, which
the P2P envelope cannot. Findings:

- The measured envelope points and the green "envelope fit" in the overlay track the data
  well; **the misleading element of `plot_q_envelope_overlay` is the red candidate line
  under `q_source="best"`**, which draws the (usually wrong) `Q_profile` value with an
  authoritative label while the mismatch information (`candidate_agrees=False`,
  slope mismatch 1.4–4×) is computed but visually understated and never propagated into
  any validity field of the profile estimate itself.
- Bias mechanisms of the envelope estimator: (i) plateau contamination (§8-C, §11);
  (ii) genuine decay-rate curvature (§8-B) — both push Q high for long windows.
  Noise-rectification bias is negligible here (floor ≫ broadband noise).
- The anchor-at-first-window convention is harmless on these records (first windows are
  high-SNR) but couples the whole overlay to a single window's amplitude; an
  early-median anchor would be more robust.

## 11. Frequency-Estimation Analysis

- Frequency *estimation* per se is healthy: DFT+Lorentzian and NLS agree with the
  segment-demodulated mean frequency at the sub-mHz level on the decay region.
- The problem is frequency *propagation into Q*: the profile estimator **fixes** $f$ at
  `f_nls` and never re-examines it; the $\delta\!f\cdot\tau$ law (§9) then applies. Since
  the true frequency moves by far more than the tolerance during the window, no constant
  $f$ exists that keeps the model coherent — the failure is *not* fixable by a better
  constant-frequency estimate.
- Spectral leakage, aliasing, and sampling-interval errors were checked and are
  irrelevant at these parameters (uniform timebase to 1.5×10⁻⁴; tone at 7.67 Hz vs
  Nyquist 74.5 Hz).

## 12. Segmentation Analysis

- Both records begin at (or within seconds of) the release; no pre-trigger content.
  Ring-down start identification is not the problem for offset-0 windows.
- The dangerous segmentation is **downstream**: the $3\tau_{\rm est}$ crop inherits any
  `tau_est` error (Mechanism D). Specimen: crop = 107 s of a 12 600 s window.
- Windows extending past ≈ 12 000–15 000 s (where the decay meets ≈ 3× plateau) include
  driven dynamics and re-excitations; envelope estimates from such windows are biased by
  +30–80 % (notebook §5.3b, real-data panel of `fig09`).
- Workflow hazard (documented, not a library bug): `MokuPhasemeterObject(start_time=…)`
  is an **offset from the file's first sample**, not an absolute time-column value. The
  Post-Vibe file's time column starts at 9000 s; passing `start_time=9000` silently
  selects the plateau. This likely contributed to earlier notebook-to-notebook
  inconsistencies.

## 13. Noise / SNR Analysis

Broadband noise: σ ≈ 1.3–1.9 cycles per-segment residual; SNR at release ≈ 400; SNR ≈ 10
even at the plateau boundary. E1 shows all estimators exact at this SNR. The dominant
"noise-like" component is the **narrowband driven plateau** — nonstationary, centered on
the signal frequency, amplitude ≈ 10× the broadband noise. Treating it as white noise is
what invalidates the profile CI ($\chi^2$ on $10^6$ samples) and the envelope's 5 %-of-max
floor logic. **Conclusion: "noise" in the generic sense is not the root cause; the
specific structured residual (plateau) is a secondary cause for envelope methods only.**

## 14. Alternative Estimator Experiments

- **Segmented demodulation + floor-corrected log-linear fit** (implemented in the
  notebook): accurate to < 2 % on all controlled experiments including measured drift and
  plateau; stable across windows on real data; additionally yields $f(t)$, $A(t)$,
  local $\tau(A)$, and the plateau level. This is the recommended basis for the production
  estimator (§19). It is essentially "log-decrement done right": incoherent in phase,
  coherent within segments, explicit floor model, robust regression.
- **Peak-to-peak log-envelope** (`q_envelope_diagnostic`): same family; adequate when the
  window is truncated at ≈ 3× plateau, biased beyond; lacks the frequency channel.
- **Prony/AR, matrix-pencil, spectral-linewidth approaches** were considered and not
  pursued: they share the constant-frequency/constant-decay pole model and would inherit
  Mechanism A; linewidth methods additionally need stationarity the records lack.
- **Coherent fits with polynomial/spline phase** could in principle track the drift, but
  add optimization fragility for no benefit over demodulation at these SNRs.

## 15. What Is Actually Causing the Failure

Evidence-graded:

1. **Demonstrated (controlled reproduction):** amplitude-dependent frequency drift →
   decoherence of all phase-coherent estimators (A). E2c reproduces the field failure
   *class* with only this ingredient: arbitrary valid-but-wrong Q spanning 0.51×–3.80× of
   truth depending on noise seed and initialization, i.e. the exact value is a lottery —
   precisely the real-data phenomenology (canonical windows 0.65×/0.25×, 0.45× on the
   same window in a round-off-level-different session, 12× window scatter).
2. **Demonstrated:** `tau_est` collapse → crop cascade (D), specimen §4/§12.
3. **Demonstrated:** driven plateau → envelope-Q high bias growing with window (C),
   E3 + synthetic/real window scans.
4. **Demonstrated (measurement):** amplitude-dependent damping → no single true Q;
   window-dependence of *all* single-$\tau$ estimators (B).
5. **Demonstrated:** profile-likelihood `valid` status and CI are blind to
   misspecification (all biased cases report `valid` with ~10⁻⁴ CIs).

## 16. What Is Not Causing the Failure

- **Broadband noise / low SNR** (E1 exact at matched SNR; SNR ≈ 400).
- **Multiple modes / beating** (single peak, −100 dB neighbors; §5).
- **Sampling-rate or timebase errors** (uniform to 1.5×10⁻⁴).
- **Optimizer bugs, bad initialization, or bounds** in the narrow sense: with a correct
  model (E1) every path converges cleanly; earlier bound-artifact issues were already
  fixed and did not resurface. `tau_init` sensitivity on real data is a *symptom* of
  Mechanisms A/B (many near-equivalent wrong optima), not a cause.
- **Missing ring-down start** for the offset-0 windows (both records begin at release).

## 17. Confidence Level / Remaining Uncertainties

High confidence (multiple independent lines of evidence): Mechanisms A–D, the exoneration
of noise, and the Pre/Post physical conclusions at the stated precision. Remaining
uncertainties:

- The *physical* origin of the frequency pull and nonlinear damping (resonator intrinsic
  vs mount/readout) is out of scope; only their signal-level consequences are established.
- The plateau is attributed to ambient drive via its spectral/temporal signature; a
  formal excitation-source identification was not attempted.
- The exact bias *direction and magnitude* of coherent fits for arbitrary drift
  trajectories is not predicted analytically here — only bounded empirically (0.5–3.8×
  at measured drift levels, seed- and initialization-dependent). The
  $\delta\!f\cdot\tau$ law is empirical but clean.
- Whether other (non-EDU) datasets in `data/` share the plateau/drift phenomenology was
  not surveyed; the SN1/SN2 files should be checked before generalizing defaults.

## 18. Recommendations

1. **Stop treating `Q_profile` as the preferred estimator for long real-data windows.**
   Its assumptions are unmeetable on drifting resonators, and its validity machinery
   cannot detect the violation.
2. **Promote an incoherent, segment-demodulated estimator to the default real-data Q
   path** (§19-P1), reporting amplitude-resolved Q plus an explicit plateau level.
3. **Wire the existing envelope-agreement check into validity**: a coherent Q that
   disagrees with the measured envelope slope (`candidate_agrees=False`) must not be
   `valid`, must not be batch-preferred, and must not be drawn as "best" without a
   mismatch warning in the overlay.
4. **Add a drift diagnostic** ($\widehat{\delta\!f}\cdot\hat\tau$ from per-segment
   frequencies) and gate all coherent estimators on it.
5. **Fix the crop cascade**: bound `tau_est` by the envelope seed (e.g. reject NLS
   `tau_est` differing from the envelope $\tau$ by more than ~3× and fall back to the
   envelope value), and never crop below a few envelope decay times.
6. Report Q with **bootstrap/segment-scatter uncertainties**, not white-noise $\chi^2$.

## 19. Proposed Codebase Evolution

**P0 — Guardrails (small, backward-compatible, immediate):**

- `analyzer.py`: cross-check `tau_est` against the envelope diagnostic already computed in
  the pipeline; on disagreement > 3×, use the envelope $\tau$ for cropping and set
  `tau_est_low_confidence`. Addresses Mechanism D. Test: Post-Vibe offset-9000 specimen
  must no longer crop to < 1 envelope-$\tau$.
- `analyzer.py` `_run_analysis_pipeline` + `q_profile.py`: demote `Q_profile` to
  `status="warning"`, reason `envelope_mismatch`, when
  `Q_envelope_candidate_agrees is False`. `batch_analyzer._result_q_value` must skip it.
  Backward-compatible (fields unchanged; statuses become honest). Tests: E2c-style
  synthetic must not yield a `valid` profile Q.
- `plots.py` overlay: annotate the candidate line with its status and the slope-mismatch
  number when `candidate_agrees=False` (e.g. dashed line + "MISMATCH ×2.3"). UI-only.

**P1 — New default estimator (moderate, new module `ringdownanalysis/demod.py`):**

- `SegmentedDemodEstimator.estimate(t, data, fs, seg_dur=…)` →
  per-segment $t_i, f_i, A_i, \sigma_i$; plateau estimate from the late-record amplitude
  distribution; contiguous decay-region selection ($A > k\,A_{\rm floor}$, default
  $k=3$); floor-corrected weighted log-linear fit; outputs `Q_demod`, `tau_demod`,
  `Q_demod_ci` (from segment scatter / block bootstrap), `Q_vs_amplitude` (per-band),
  `f_vs_amplitude` (pull coefficient), `drift_mHz`, `plateau_cycles`, and a
  `coherence_ratio` diagnostic ($\widehat{\delta\!f}\cdot\hat\tau$).
- Integrate as pipeline step with fields `Q_demod*`; batch prefers valid `Q_demod` for
  long records; `Q_profile` remains for short/coherent records
  ($\widehat{\delta\!f}\cdot\hat\tau < 0.01$ and window $\lesssim \tau$).
- Not backward-breaking: additive fields; batch preference change behind an option for
  one release, then default.

**P2 — Model extensions (optional, physics-grade):**

- Nonlinear-damping fit $1/\tau(A) = 1/\tau_0 + \beta A$ on the demodulated amplitude;
  report $(\tau_0, \beta)$, the zero-amplitude Q, and the fitted $f(A)$ pull coefficient
  and zero-amplitude frequency. This turns Mechanism B from a nuisance into measurement.

**P3 — Estimator-selection architecture:**

- A lightweight classifier on the demod diagnostics chooses/weights estimators:
  coherent (short, drift-free) → profile; long/drifting → demod; plateau-dominated →
  limits only. Cross-estimator agreement within tolerance becomes a hard condition for
  `valid` finite Q; disagreement yields the incoherent value with `warning` and reasons.

## 20. Validation and Regression-Test Strategy

**Synthetic fixtures** (extend `signal.py` or test helpers; all deterministic):
linear and amplitude-proportional frequency drift; injected empirical $f(t)$ (stored as a
small fixture array); AR(2) driven plateau; amplitude-dependent damping; baseline wander.
Behavioral asserts:

- E1-class: all estimators within 1 %.
- E2c-class: demod estimator within 2 % of truth; **no coherent estimator reports
  `valid`** (drift gate or envelope-mismatch gate must fire).
- E3-class: demod/envelope with floor model within 3 % for windows up to 6 h.
- Specimen-class (plateau-dominated window): crop must retain ≥ 1 envelope-$\tau$ of data;
  result must be a limit/invalid, never a confident finite Q.
- CI calibration: bootstrap CIs achieve nominal coverage on E1/E3 ensembles.

**Real-data regression** (files already in `data/ODIN/`): pin the demod results for
`20260321_EDU_R1.csv.zip` ch1 and `20260325_EDU_R1.csv.zip` ch2 —
whole-decay Q within ±5 % of (8.9×10⁴, 1.0×10⁵), per-band Q values within ±10 %, plateau
16–18 cycles, drift +1.1/+0.3 mHz — and a **window-stability test**: max/min of the
default Q over the standard window sweep must be < 1.2 (currently 12 for `Q_profile`).

**Success metrics:** window-sweep stability < 1.2 on both EDU records; no `valid` finite
Q on drift-injected synthetics from coherent estimators; overlay never draws an unflagged
mismatching envelope; batch statistics on the EDU pair reproduce the §4-notebook physical
conclusions without manual tuning.

## Appendix A — Bugs and hazards found that are separate from the core Q failure

1. `MokuPhasemeterObject(start_time=…)` is a file offset, not an absolute time value —
   with the Post-Vibe file's time column starting at 9000 s this silently selects the
   wrong window (workflow hazard; documented in notebook §1/§5.1).
2. `RingDownAnalyzer.estimate_tau` returns the (possibly user-provided) seed on fit
   failure without any flag other than a log line; a failed fit is indistinguishable from
   a successful one in the result fields (`analyzer.py:444–454`).
3. The profile-Q 95 % CI is a white-noise $\chi^2$ construct on ~10⁶ samples; under any
   misspecification it is orders of magnitude too small. It should not be displayed
   without a goodness-of-fit qualifier (addressed by P0/P1 above).
4. `_select_q_for_overlay(q_source="best")` label reads like an endorsement; it can select
   a Q that the very diagnostic being plotted disagrees with (addressed by P0 overlay
   annotation).
