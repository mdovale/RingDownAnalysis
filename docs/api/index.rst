RingDownAnalysis
================

Frequency and quality factor estimation of exponentially decaying sinusoids (ring-down signals).

Quick Links
-----------

- **API Reference** :doc:`modules` — Classes and functions
- **Data Format** :doc:`data_format` — CSV and MAT file specifications

Overview
--------

This package provides:

- **Signal generation**: Synthetic ring-down signals with configurable parameters
- **Frequency estimation**: NLS (nonlinear least squares) and DFT methods
- **CRLB calculation**: Cramér-Rao lower bound for ring-down signals
- **Real data analysis**: Load CSV/MAT files (Moku:Lab Phasemeter format) and run the full pipeline
